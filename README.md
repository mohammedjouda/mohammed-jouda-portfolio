## 🚀 Deployment & Hosting

This project is fully static and zero-dependency, deployable within seconds on:

### Option 1: Vercel (Recommended)
1. Import repository on [Vercel](https://vercel.com).
2. The bundled `vercel.json` automatically configures SPA rewrites, immutable asset caching, and security headers.
3. Add your custom domain `mohammedjouda.com`.

### Option 2: Netlify
1. Import repository on [Netlify](https://netlify.com).
2. The bundled `_redirects` file automatically handles client-side SPA routing.

### Option 3: Apache / cPanel / Shared Hosting
- Upload all root files to `public_html`.
- The bundled `.htaccess` ensures HTTPS redirection, SPA routing fallback, asset expiration headers, and custom 404 handling.
